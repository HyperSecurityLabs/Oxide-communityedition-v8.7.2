#🚨 OXIDE COMMUNITY EDITION — PROJECT TRANSITION NOTICE
A New Chapter Begins.

To everyone who has followed, tested, starred, contributed to, or supported OXIDE Community Edition — thank you.
After extensive development and experimentation, HyperSecurity Offensive Labs is moving active OXIDE development to a new dedicated repository focused specifically on web vulnerability research and security testing.
# 🛰️ What is happening?

The existing OXIDE Community Edition v8.7.2 repository is being archived.
This does not mean the project is abandoned.
The repository will remain available as a historical reference, release archive, and record of the Community Edition development cycle. Existing commits, documentation, releases, and project history remain part of OXIDE's evolution.

#⚡ Where is development moving?
Active development is continuing in our new repository:
OXIDE Web Vulnerability Scanner
The new project provides a cleaner foundation for developing and improving the scanner's web-security capabilities, with a stronger focus on modular architecture and individual vulnerability-testing components.

> Future development may include improvements across areas such as:
Web vulnerability detection
API security testing
Reconnaissance and attack-surface analysis
Modular vulnerability scanners
HTTP analysis
Detection and validation engines
Security research datasets
Automated reporting
AI/ML-assisted security research
Android/Termux workflows
Authorized penetration-testing environments
> 
# 🧩 Why the transition?

OXIDE has grown considerably during the Community Edition development cycle.
As the codebase expanded, some experimental modules and older components became difficult to maintain independently. Rather than continuously stacking new functionality onto an increasingly complex foundation, we're taking the opportunity to separate the next generation of development into a cleaner project structure.
This allows future modules to be developed, tested, isolated, and improved more systematically.

#🔒 Important disclaimer

OXIDE is a security research and authorized testing tool.
It is intended for:
✓ Authorized penetration testing
✓ Security research
✓ CTF environments
✓ Defensive testing
✓ Red-team laboratories with permission
✓ Systems owned or explicitly authorized by the tester
Users are responsible for ensuring that their activities comply with applicable laws, regulations, contracts, and authorization requirements.
Do not use OXIDE against systems, networks, accounts, APIs, or infrastructure without explicit permission.

# 🗃️ What happens to this repository?

This repository is being preserved rather than deleted.
The v8.7.2 Community Edition represents an important stage in OXIDE's development and will remain available for historical and reference purposes.
No promise is being made that every legacy component in this repository will receive future development.
New features and major improvements should be expected in the new repository instead.
